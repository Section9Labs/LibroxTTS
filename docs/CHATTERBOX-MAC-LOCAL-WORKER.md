# Owned local Mac chapter work

`ChatterboxMacLocalWorker` is a native Mac SDK actor that owns a complete local operation: claim, exact source/options admission, resident preparation and backend binding, narration/export, private verified custody, immutable handoff publication and journal completion. Construction does not load a model. The public production constructor accepts only the fixed Standard model and stock conditioning identity before loading or cached-audio copying. Synthetic backend injection remains internal to tests.

The host supplies its own current Worker account session/gate and authorized, existing role directories. Reader source/plan publications are immutable inputs. Worker state, exports, custody and complete publications have separate roots. Directory identities and role aliases are checked at admission and subsequent stage boundaries. The Worker never opens the Reader's mutable journal or receives a book database/recording URL.

The public constructor also requires a dedicated `artifactBudget:` owner scoped
to exactly Exports, Custody and Publications; State/model/Reader roots are
excluded. The Worker owns that allowance lifecycle and closes the transferred
budget on terminal shutdown. See `CHAPTER-WORKER-STORAGE-ADMISSION.md` for the
conservative fresh/recovery admission, measured boundary observations and joined
settlement. These are soft admission checks, not a pre-write codec cap or OS quota.

Claims start disabled. Explicit enable is fenced by lifecycle revision and account validation. One operation owns the preparation/render/codec/publication chain. Its exact task is registered in a nonisolated mutex-backed cancellation slot, so disable/shutdown can signal it even while a model actor is executing synchronous work.

The nonisolated synchronous `stopClaims()` method is the host's same-event-turn admission/cancellation fence. It must be called directly from lifecycle disable/account/sleep/quit handling; scheduling an async disable call in a new Task does not provide that same-turn guarantee. The host then awaits `disable()` or terminal `shutdown()` as the join barrier. Disable disables journal claims, cancels the owned operation and awaits a separate cleanup task. That cleanup first awaits the **original producer task's result**, including each component's joined child operations, and only then calls the journal's after-join release. Caller cancellation shares the same cleanup. Concurrent stops are counted through their entire transition; enable cannot pass an unfinished stop or an older paused enable. Disabled/cancelled outcomes are interruptions, not renderer failures requiring a new demand. Shutdown additionally releases the resident runtime and closes journal ownership after joining. Normal disable may retain a successfully loaded model for later explicit work. A higher-level service adapter must not repeat an already completed journal relinquishment; connection disposal must await terminal shutdown.

During new narration the existing bound renderer authorization checks the Worker generation and current Reader authority at its preparation/passage/output boundaries, in addition to the original account/resource/output guards. No model arithmetic, solver steps, sampler, normalization, voice or precision policy changes. A Reader intent cancellation observed at a boundary rejects further acceptance. Immediate active-task cancellation still requires the host/orchestrator stop signal; this component does not claim a continuous distributed cancellation lease.

Recovered completed/planned references are only lookup candidates. The default recovery path must actually receive, privately copy and decode complete immutable audio under the new Worker session. Missing/corrupt candidates fail; they do not silently trigger fresh inference. An explicit `renderFresh` action remains distinct. No AAC-to-ALAC synthesis reuse is introduced: the full request identity includes delivery. Both recovery and new generation admit the complete portable options fingerprint, including grouping/direction/expression/seed, before accepting content. The shared fingerprint retains six frozen legacy synthesis/delivery digests; it is a metadata admission correction, not a new model oracle or cache migration.

Physical publication remains separate from Reader acceptance. The return value carries the exact read set and immutable handoff reference. The Reader must perform actual receive/adoption and its own atomic `acceptVerifiedHandoff` check. A Worker file or `.published` checkpoint never activates playback by itself. Final Worker results are also checked against current account, Reader intent, cancellation and lifecycle revision before returning.

Worker timing uses a monotonic clock and includes admission, claims, rendering, selected codec/readback, private copy/publication and joined cleanup. Model loading is measured separately when a cold prepare occurs. Reader copying/acceptance, cloud transport and playback startup are excluded. Verified cached-audio reuse is explicitly labeled and must not be presented as fresh-model throughput. No speed or voice-quality claim follows from synthetic tests.

Validation uses gated synthetic preparation/narration plus actual AAC encoding/readback/custody and immutable publication. It exercises cancellation during loading/rendering, cancelled stop callers, lock retention until producer exit, repeated and concurrent stops, paused enable ordering, unchanged-intent restart after disable, current Reader cancellation, wrong backend/stock identity, directory replacement, exact cache recovery and inconsistent cached-plan rejection. No production model initialization, actual GPU narration, installed/signed host, App Group or CloudKit operation runs in these tests.

The app provider remains unavailable on its frozen SDK until the reviewed source is committed and integrated. Reader and Worker data-admission components now exist; control-archive retention, concrete service/catalog wiring and separately authorized signed real-generation acceptance remain required. This source checkpoint is not a release, complete cloud service, whole-chapter listening approval or 5x result.
