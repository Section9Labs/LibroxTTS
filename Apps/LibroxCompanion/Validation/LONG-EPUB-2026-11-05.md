# Long EPUB import correction

Broken Stars had one original spine entry of 138,085 UTF-16 units, exceeding the 131,072-unit renderer input bound. Its original EPUB is 2,913,314 bytes; file size was not the cause.

The companion importer now preserves the complete extraction and divides long spine entries into bounded narration parts, preferring sentence or word boundaries. Part keys record the original spine index and exact UTF-16 range; the extraction revision is `companion-epub-swiftsoup-parts-2`. Smaller and silent entries retain one key each. Renderer and transport bounds are unchanged. Companion part indices must not be treated as original reader spine indices.

Six importer tests passed, including byte-for-byte synthetic long-EPUB reconstruction, Unicode bounds, silent entries, and the user's actual cached EPUB. The real book imports as 63 narration sections from 62 original spine entries; only one entry requires splitting. Maximum resulting section length is 122,122 UTF-16 units. No book text or original EPUB is committed.
