# Librox Companion

## Design plan

Archetype: menu bar extra, one compact panel, a separate native Settings window.
The feeling is calm. Books and one truthful activity sentence are the content.
No catalog, reader, dashboard, invented percentage, or model engineering controls.

Information architecture: status, preparation toggle, books, Settings and Quit.
Settings contains language, delivery format, explicit login opt-in and narration
file installation. Native colors, text styles, controls and focus behavior apply.

Command map: Add Book imports EPUB, UTF-8 text or an exact Librox export; Prepare
submits a durable whole-book request; Pause stops this Mac after joining work;
Stop This Request withdraws only the Mac reader's intent. Settings is Command-,
and Quit is Command-Q. Phone Play/Pause never changes preparation intent.

Empty state: a short explanation and Add Book. Offline/account/model errors show
the actual failure and a retry action. No rendered/ready state comes from titles
or transfer metadata. The initial app does not register a login item or load a
model until preparation is enabled.

The current backend admits English/Spanish. Multilingual describes the model,
not a claim that the remaining languages have passed this native pipeline.
